# Privacy Notice

**The plugin opens search and page tabs on your device. The page text the assistant reads is exactly what the tab displays.**

## What happens to your data

Every search and page load runs in a visible browser tab inside this app.

Nothing is sent to the app maker or to any third party — no analytics, no ads, no trackers, no accounts.

## Tabs

You can inspect every tab at any time: the search-results tab shows exactly what was asked, and the opened page is what the assistant read.

Wipe-on-close (on by default in Browser settings) erases cookies, site storage and cache when this app closes.

## The request log

Every requested URL is logged on this app's home screen, so you can always see exactly what was fetched.

The log lives only on your device, and you can delete it at any time with the Delete-all button.

## Captchas

If a site asks for a human check, a notification points you at the tab. You solve it yourself — this app never bypasses a check.

## Open source

This app is fully open source — every line it runs is public and auditable.

## Changes

If this notice changes, the updated version will ship inside the app.
